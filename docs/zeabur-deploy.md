# OHeas Backend — Zeabur 部署指南

> 预计时间：20 分钟 | 费用：~$5/月（Free 计划可试用）

## 前提

- [GitHub 仓库](https://github.com/wannathan20-sketch/OHeas) 已推送最新代码
- [Zeabur 账号](https://dash.zeabur.com)（GitHub 登录即可）
- Apple Developer 账号（如需 Apple Sign In）
- OpenAI API Key（如需 RAG 语义检索，不设置则自动降级到本地匹配）

---

## 架构

```
Zeabur 项目: oheas
├── oheas-db      (PostgreSQL 服务)
└── oheas-api     (API 服务 — 从 GitHub backend/ 目录 Dockerfile 构建)
        ↓
   iOS App → HTTPS → oheas-api.zeabur.app → oheas-db:5432
```

> 💡 也可以把 PostgreSQL 换成 [Supabase](https://supabase.com)（免费额度更大）。见文末「Supabase 替代方案」。

---

## 第一步：创建 Zeabur 项目

1. 打开 [Zeabur Dashboard](https://dash.zeabur.com)
2. 点击 **Create Project** → 命名 `oheas`
3. 区域选 **Singapore** 或 **Hong Kong**（对国内延迟更低）

---

## 第二步：添加 PostgreSQL 服务

1. 进入项目 → **Add Service** → **Database** → **PostgreSQL**
2. 服务名设为 `oheas-db`（默认即可）
3. 等待 30s 部署完成
4. 进入 oheas-db → **Variables** 标签页，记录以下值：

| 变量 | 示例值 |
|------|--------|
| `POSTGRESQL_HOST` | `xxx.zeabur.internal` |
| `POSTGRESQL_PORT` | `5432` |
| `POSTGRESQL_USER` | `postgres` |
| `POSTGRESQL_PASSWORD` | `<auto-generated>` |
| `POSTGRESQL_DATABASE` | `postgres` |

---

## 第三步：生成 JWT Secret

```bash
openssl rand -hex 32
# 输出类似：a1b2c3d4e5f67890abcdef1234567890abcdef1234567890abcdef1234567890
```

记下这个 64 字符的 hex 值，后续填入环境变量。

---

## 第四步：添加 API 服务

1. 进入项目 → **Add Service** → **GitHub**
2. 授权并选择 `wannathan20-sketch/OHeas`
3. 关键配置：

| 设置项 | 值 | 说明 |
|--------|-----|------|
| **Root Directory** | `backend` | 让 Zeabur 在 `backend/` 下找 Dockerfile |
| **Branch** | `main` | |

4. 点击 **Deploy**（先不配置环境变量，等构建完成后再加）

Zeabur 自动流程：
```
检测 backend/Dockerfile → docker build → 启动容器
```

---

## 第五步：配置环境变量

等首次构建完成（约 2 分钟），进入 oheas-api → **Variables** → **Edit as Raw**，粘贴以下内容：

```env
DATABASE_URL=postgresql+asyncpg://postgres:YOUR_DB_PASSWORD@YOUR_DB_HOST:5432/postgres
JWT_SECRET=YOUR_OPENSSL_RAND_HEX_32
APPLE_TEAM_ID=
APPLE_CLIENT_ID=com.oheas.mvp
OPENAI_API_KEY=
DEBUG=false
```

> ⚠️ 把 `YOUR_DB_PASSWORD` 和 `YOUR_DB_HOST` 替换为第二步记下的实际值。  
> ⚠️ 如果密码含特殊字符（`@` `#` `%` 等），需要 URL encode：`@` → `%40`、`#` → `%23`。

保存后 Zeabur 自动重启服务。

---

## 第六步：验证部署

### 6.1 获取公网 URL

oheas-api → **Networking** → 复制域名（如 `oheas-api.zeabur.app`）。

### 6.2 健康检查

```bash
curl https://YOUR_DOMAIN/health
# 期望: {"status":"ok","db":"connected"}
```

如果 `db` 显示 `disconnected` → 检查 `DATABASE_URL` 是否正确。

### 6.3 API 文档

浏览器打开 `https://YOUR_DOMAIN/docs` — 应显示 FastAPI Swagger UI。

### 6.4 测试端点

```bash
# Auth 端点存在性测试（预期 422 或 401，不是 404）
curl -X POST https://YOUR_DOMAIN/v1/auth/apple \
  -H "Content-Type: application/json" \
  -d '{"identity_token":"test"}'

# Sync 端点存在性测试
curl https://YOUR_DOMAIN/v1/sync/changes?since=2024-01-01T00:00:00 \
  -H "Authorization: Bearer test"
```

在 iOS App 的 Settings → Account 中填入后端 URL：

然后即可测试 Sync、Chat（RAG）等功能。

## 日常运维

### 更新部署

推送代码到 `main` 分支 → Zeabur 自动重新构建（约 2-3 分钟）。

```bash
git add -A && git commit -m "backend: fix something" && git push
```

如需禁用自动部署：oheas-api → **Settings** → 关闭 **Auto Deploy**。

### 查看日志

oheas-api → **Logs** → 实时容器输出（stdout/stderr）。

### 数据库备份

oheas-db → **Backups** → 手动备份或设置自动备份策略。

## 常见问题

### Q: 构建失败 — `COPY app/ ./app/` 找不到文件？

确认 Root Directory 已设为 `backend`。如果不是，Zeabur 会把仓库根目录作为构建上下文，找不到 `app/` 目录。

### Q: alembic migration 失败？

查看 oheas-api → **Logs**。常见原因：

- DATABASE_URL 格式不对（检查 `+asyncpg` 是否遗漏）
- 密码特殊字符未 URL encode
- PostgreSQL 服务未运行

### Q: `db: disconnected`？

1. 确认 oheas-db 服务状态为 **Running**
2. 检查 DATABASE_URL 中 HOST 是否正确（应使用 Zeabur 内部地址，非公网地址）
3. 如果用 Supabase，检查 IP 白名单是否允许外部连接

### Q: RAG 检索不工作？

检查 `OPENAI_API_KEY` 是否已设置。不设置时自动降级到本地 token 匹配（功能正常但精度较低）。

Zeabur 托管 PostgreSQL 如果不提供 `vector` 扩展，迁移会跳过 pgvector 索引并保留文本 fallback；需要语义向量检索时建议改用支持 pgvector 的 Supabase/Postgres。

## 附录 A：Supabase 替代方案

如果更喜欢 Supabase（免费 500MB 数据库 + 自动备份），替换第二步：

1. [Supabase](https://supabase.com) 创建项目
2. **Project Settings → Database → Connection string → URI**
3. 用 **Session Pooler**（port 6543），不用 Transaction Pooler（port 5432）
4. 连接字符串格式：

```
postgresql+asyncpg://postgres.[project-ref]:[password]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?sslmode=require
```

5. 把这个字符串作为 `DATABASE_URL` 填入 Zeabur 环境变量
6. **不需要** Zeabur 的 PostgreSQL 服务（可删除 oheas-db）

## 附录 B：本地 vs 生产对照

| 场景 | DATABASE_URL | 启动命令 |
|------|-------------|---------|
| 本地 Docker | `postgresql+asyncpg://oheas:oheas@db:5432/oheas` | `docker compose up` |
| 本地裸跑 | `postgresql+asyncpg://oheas:oheas@localhost:5432/oheas` | `uvicorn app.main:app --reload` |
| Zeabur 生产 | Zeabur PG 或 Supabase 连接串 | 自动（Dockerfile CMD） |
